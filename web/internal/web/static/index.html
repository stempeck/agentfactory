        Settings

        Every configuration document under .agentfactory/ — what the console may change, and when a change takes effect. Each panel saves one file through af, the single validator and writer, and saves back everything it read: keys this console has never heard of ride through untouched.

        Dispatch routes

        A route may carry several labels — separate them with commas. The model column pins a profile from models.json; leave it blank to use the agent's own model.

        Advanced — raw dispatch.json

        The document exactly as af wrote it. The controls above overlay this text when you save. Labels, agents and model pins belong to the route rows — change those there; change everything else here. Editing them in both places, or changing which routes exist in both, is refused rather than guessed. A key af's schema does not declare is refused with a 422 naming the key — remove it, or propose it for af's schema.

        ✦
        dispatch.json saved.

        Startup

        Auto-dispatch on startup Start the dispatcher automatically when the factory boots.
        Startup agents

        Absent and empty are different documents to af: absent means ALL, [] means none. Whichever you pick is what gets written.

        Advanced — raw startup.json (including the recovery block)

        The 14 recovery knobs live here, next to af's own error messages. Note that af materializes a default for any recovery integer you leave at 0 the first time this file is saved, so a stated 0 comes back as the default. A key af's schema does not declare is refused with a 422 naming the key — remove it, or propose it for af's schema.

        ✦
        startup.json saved.
