        Put this view on a Miro board
        1. Click Copy for Miro.
        2. Open any Miro board (any plan, including Free) and paste on the canvas with Cmd/Ctrl+V. Miro builds a diagram from native shapes. Alternatively: Creation bar, Formats, Diagram, Build with code, then paste into the code panel.
        3. Edit in focus mode. Do not choose "Switch to free-form" if the code and shapes should stay in sync.
        4. Paste once per view. Flowchart views become editable shapes; dynamic (sequence) views become native shapes that are not yet visually editable.
        5. Fallback: Download PNG and drag the file onto the board.

        These steps come from Miro's help article "Create Mermaid diagrams" and were not tested on a board.
