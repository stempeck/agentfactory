You run a factory of AI agents. Can you hand it an agent someone else wrote - without trusting it blind? And can you run the whole thing on the ChatGPT subscription you already pay for?

Last month agentfactory could do neither. Now: af plugin install adds a third-party agent from a git repo - install IS the consent step, af records its source and content hashes, and af plugin verify tells you later whether a single byte has drifted. A name that would shadow a core agent is REFUSED.

af gateway auth import points the model gateway at your ChatGPT subscription instead of an API key - your Claude Code agents run on the plan you've already got, and the token is never printed. And every relaunch now runs on exactly the config you set, not whatever an earlier launch left behind.
