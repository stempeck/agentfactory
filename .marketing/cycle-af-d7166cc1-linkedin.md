You hand an autonomous agent a context window and walk away. It fills it. What did it actually spend to get there? Was that normal? Did the change you shipped last week help, or did you just tell yourself it did?

For a long time my honest answer to all three was "no idea."

The new release of agentfactory gives its agents token economics = it SEES what each run generates (and reports "null," never a fake zero, when it can't measure), it BOUNDS a sub-agent that would oversubscribe a shared backend before it even launches, and it PROVES whether a change helped with one compare command that VOIDS the verdict rather than inventing a win. Off by default.

If you run agents on long workflows - can you prove your last optimization actually worked? Happy to help.
